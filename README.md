# Quran App

An ad-free, offline-first Quran reader built as a Progressive Web App.

**Live:** [quran.awab.design](https://quran.awab.design)

## Features

- **All 114 surahs, offline.** The service worker precaches the full text, so the app works without a connection once installed.
- **Two reading modes.** Read by surah as one continuous scroll, or by mushaf page in a book-style spread.
- **Continue reading.** Remembers your last position and takes you back to it.
- **Bookmarks and search.** Save verses and search across the Quran.
- **Reading streaks.** A streak banner tracks daily reading, and verses can be shared as images.
- **Daily athkar.** Morning, evening and sleep remembrances with a tap-to-count tracker.
- **Command palette.** Keyboard-first navigation to any surah or page.
- **Arabic typography.** Scheherazade New with adjustable font sizes.
- **Multilingual interface.** English, Arabic (RTL) and Turkish.
- **Installable.** Add to the home screen on iOS, Android or desktop.

## Tech stack

- [Next.js](https://nextjs.org/) (App Router) and TypeScript
- [Tailwind CSS](https://tailwindcss.com/)
- [Serwist](https://serwist.pages.dev/) for the service worker and offline precaching
- [next-intl](https://next-intl.dev/) for i18n and RTL
- [Framer Motion](https://www.framer.com/motion/) and [Headless UI](https://headlessui.com/)
- Quran text from the [Quran.com API](https://api-docs.quran.com/)

## Getting started

Requires Node.js 24.

```bash
git clone https://github.com/awabadam/quran-app-v0.2.git
cd quran-app-v0.2
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server |
| `npm run build` | Production build (includes the service worker) |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |

The service worker is only generated by `npm run build`, so test offline behaviour against a production build.

## Project structure

```
app/[locale]/
├── [surah]/       # Surah reader
├── bypage/        # Mushaf page reader
├── athkar/        # Daily remembrances
├── bookmarks/     # Saved verses
├── search/        # Search
└── about/
app/sw.ts          # Service worker (Serwist)
components/        # UI components
context/           # Reading position, settings, bookmarks
i18n/, messages/   # Locales: en, ar, tr
lib/               # Data access and utilities
```
